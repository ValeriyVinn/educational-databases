# Educational Databases

A learning repository for database design, SQL, database
administration, migrations, seeds, backups and restoration.

## Databases

- PostgreSQL
- MongoDB
- Other databases

## PostgreSQL

Current educational databases:

- educational

## Repository structure

- postgresql/ - PostgreSQL learning projects
- mongodb/ - MongoDB learning projects
- other-databases/ - other database technologies

## Workflow

1. Pull the latest repository changes.
2. Apply database migrations.
3. Insert seed data when needed.
4. Practice database operations.
5. Commit and push repository changes.

## Purpose

The repository is the single source of truth for database
schemas, migrations and initial learning data across multiple computers.
